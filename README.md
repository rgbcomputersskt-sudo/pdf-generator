# Creative Vision PDF Generator

A polished static PDF generator built with HTML, CSS, JavaScript, and Bootstrap. It gives you a live A4 preview, editable document content, and one-click PDF export for proposals, quotations, letters, reports, and other business documents.

## Overview

This project is designed as a GitHub-friendly static web app. You can upload it directly to a repository, host it on GitHub Pages, or open it locally with any static file server.

The interface is styled to feel modern and intentional, with a dark glassmorphism workspace and a clean paper-like document preview. The preview can be customized in real time and exported as a PDF file.

## Features

- Live document preview that updates while you type.
- A4-style paper layout for professional PDF output.
- Editable fields for title, subtitle, recipient, reference number, date, main content, highlights, and footer note.
- Accent color picker to restyle the document preview.
- Responsive Bootstrap layout that works on desktop and mobile.
- One-click PDF generation using `html2pdf.js`.
- Sample content loader for quick demonstrations.
- Brand footer and website references for Creative Vision Information Technology.

## How to Run Locally

### Option 1: Open directly

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Fill in the fields and click **Generate PDF**.

### Option 2: Use a local server

If you prefer running a local server, use any static server you already have installed.

Examples:

- VS Code Live Server
- XAMPP Apache
- Python HTTP server
- Node.js static server

## How It Works

1. Enter your document information in the form.
2. The preview updates automatically.
3. Click **Generate PDF**.
4. The browser downloads a PDF file with the current preview content.

## Deployment Notes

Because this project uses CDN assets for Bootstrap, fonts, and `html2pdf.js`, an internet connection is recommended when opening the page for the first time.

To publish it on GitHub Pages:

1. Push the files to your GitHub repository.
2. Enable GitHub Pages from the repository settings.
3. Select the branch and root folder that contains `index.html`.
4. Open the published URL in your browser.
